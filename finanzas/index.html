¿Cómo identificamos un movimiento bancario?

Los movimientos generados desde la aplicación de Banco Azteca muestran un folio automático. Ese folio sirve como referencia práctica para registrar cada operación de forma consecutiva.

En el control financiero de Lucania, ese número puede utilizarse para enlazar:

  • el comprobante bancario;
  • el movimiento registrado en Excel;
  • el concepto del ingreso o gasto;
  • la clasificación contable o administrativa.
Ejemplo: si el comprobante muestra el folio 1162, ese mismo número puede registrarse en Excel como referencia del movimiento.
